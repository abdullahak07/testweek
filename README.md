# CTI Quest — COMP6012 Week 1

Interactive cyber threat intelligence course website based on the provided 51-slide COMP6012 Week 1 lecture. Eight study modules with multiple-choice checkpoints and games, XP, badges, progress tracking, and responsive design.

## Development

```bash
npm install
npm run dev
```

## Vercel

Import the repository as a **Vite** project. Build command: `npm run build`. Output directory: `dist`. No secrets or environmental variables needed.

## Modules

1. What is threat intelligence?
2. Threat actors & TTPs
3. CTI lifecycle
4. Intelligence requirements and consumers
5. Threat qualification
6. Security challenges
7. Indicators and Pyramid of Pain
8. Collection, analysis, dissemination and feedback

Scenario-based practice is fictitious and intended for education. Lecture acknowledgement: Dahj (2022), *Mastering Cyber Intelligence*.
